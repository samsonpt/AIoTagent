# ADR-003: 数字孪生与模拟器隔离，并引入模型失配

## Status
Accepted

## Date
2026-10-08

## Context
- 系统是纯软件仿真，模拟器扮演“现实”。
- 如果孪生直接复用模拟器的物理模型，前瞻仿真天然百分之百准确，孪生相关的实验结论失去说服力，属于循环论证。
- 论文 IV-D 与 VI-D 强调仿真到现实差距（Sim-to-Real Gap）及其报告。

## Decision
- 孪生独立建模（机理模型 + 数据驱动残差），只能通过 `sim/measurement.py` 测量通道获取数据。
- 模拟器包含孪生不可见的隐藏参数与未建模效应，强度由场景参数 `model_mismatch`（`low` / `mid` / `high`）控制。
- `twin/`、`edge/`、`cloud/` 禁止 import `sim/` 模型代码，由 `tests/test_isolation.py` 静态检查。

## Alternatives Considered

### 孪生复用模拟器模型
- Pros：实现量小。
- Cons：预测无误差，实验无意义，审稿必然质疑。
- Rejected。

### 孪生使用纯数据驱动模型
- Pros：不需要机理建模。
- Cons：数据量有限时外推能力差，可解释性弱，不利于根因的反事实验证。
- Rejected：采用机理 + 残差的混合方案。

## Consequences
- 需要额外实现测量通道与隐藏参数，M1 工作量增加。
- 可以按失配等级画出“仿真与现实差距对决策质量的影响”曲线，作为论文结果。
- 孪生必须输出置信度，Guard 依据置信度调整门槛。
