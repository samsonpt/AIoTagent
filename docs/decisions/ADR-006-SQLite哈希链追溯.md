# ADR-006: 用 SQLite 哈希链实现批次级追溯，不使用区块链

## Status
Accepted

## Date
2026-10-08

## Context
- 论文 IV-C 提出用区块链记录智能体动作，实现机器问责。
- 本项目是单工厂内部系统，没有多方互不信任的参与者；需要的是防篡改与可追溯，而不是去中心化共识。
- 论文同时指出区块链的链上计算开销与实时性矛盾。

## Decision
- 每条感知、决策、动作记录带批次号写入 SQLite，记录包含前一条记录的哈希，形成哈希链。
- 提供链完整性校验；校验失败时看板告警，并停止接受新的自动动作。

## Alternatives Considered

### 联盟链 / 智能合约
- Pros：与论文表述一致，支持多方审计。
- Cons：部署与运维复杂，写入延迟高，对单工厂场景收益有限。
- Rejected：在论文中说明可替换为区块链以支持跨企业供应链场景。

### 普通数据库日志
- Pros：最简单。
- Cons：无法检测篡改。
- Rejected。

## Consequences
- 追溯能力满足“按批次回答为什么被这样处理”的需求，开销低。
- 跨企业审计不在 MVP 范围内。
