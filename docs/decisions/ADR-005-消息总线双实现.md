# ADR-005: 消息总线抽象为 Bus 接口，提供 InMemoryBus 与 MqttBus 两个实现

## Status
Accepted

## Date
2026-10-08

## Context
- 演示需要真实的 MQTT（贴近 AIoT 部署形态）。
- 单元测试与批量评测需要确定性、可加速运行，且不依赖外部 broker。
- 评测矩阵规模为场景 × 配置 × 种子，需要在加速时钟下大量运行。

## Decision
- 定义 `Bus` 接口（发布、订阅、断连模拟）。
- `InMemoryBus`：同步、确定性投递，由 `SimClock` 驱动，用于测试与评测。
- `MqttBus`：基于 paho-mqtt，连接 Mosquitto，用于演示。
- 两者使用同一套主题命名。

## Alternatives Considered

### 只用 MQTT
- Pros：只有一套实现。
- Cons：测试依赖 broker，投递时序不确定，评测无法逐位复现，也无法加速。
- Rejected。

### 只用进程内总线
- Pros：最简单。
- Cons：演示缺乏真实 AIoT 通信形态。
- Rejected。

## Consequences
- 需要保证两种实现的语义一致，`MqttBus` 用少量集成测试覆盖（可选运行）。
- 断网场景在 `InMemoryBus` 中通过断连模拟实现。
