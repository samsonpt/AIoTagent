# ADR-004: 只在事件触发时调用 LLM

## Status
Accepted

## Date
2026-10-08

## Context
- 产线遥测频率高（1~10 Hz），逐条调用 LLM 成本与延迟都不可接受。
- 论文 VI-B 提出“智能体应判断何时需要深度推理、何时反射控制即可”。
- 安全相关的快速动作（断针急停、超温降电流）要求毫秒级响应，不能依赖 LLM。

## Decision
- 边缘智能体负责所有常规与安全相关的快速控制，不调用 LLM。
- 云端 LLM 只在两类情况下被唤醒：边缘上报异常事件；AOI 缺陷率超过阈值（默认：最近 5 个批次缺陷率超过故障前基线均值 + 3σ）。
- 提供消融开关 `use_event_trigger`，关闭时改为周期性调用（默认每 60 仿真秒），用于量化成本与质量的取舍。

## Alternatives Considered

### 周期性调用 LLM
- Pros：实现简单，不会漏掉缓慢变化。
- Cons：调用量大、成本高，大部分调用无事发生。
- Rejected：保留为消融对照组。

### 完全不用 LLM，只用规则与优化
- Pros：确定性强。
- Cons：无法完成跨工序根因分析与知识检索，与论文主题不符。
- Rejected：作为 `baseline_rule` 基线。

## Consequences
- 缓慢漂移可能在越过阈值前未被云端察觉，需要边缘 SPC 判异覆盖。
- 评测中报告 LLM 调用次数、token 与成本，回答 RQ3。
